# 管理员手册

## 知识库管理员

该图片展示了企业管理后台中“添加管理员”的操作界面，用于说明在创建新管理员时如何为其分配特定的功能权限，特别是勾选“知识库”权限的操作步骤。图中有一个手形光标指示正在点击“知识库”选项。

界面顶部面包屑导航显示：企业设置 / 管理员权限 / 添加管理员。

左侧为系统导航菜单，可见部分从上至下依次为：
会议室
工作台
费用中心
安全
数据报表
企业文化
企业设置（当前展开），其子菜单包括：
- 企业信息
- 管理员权限（当前选中高亮）
- SSO 帐号登录
- 数据迁移
- 企业专属表情包
功能管理
邮箱
视频会议

右侧主内容区域是一个弹出的模态窗口或面板，顶部有两个标签页：“超级管理员”和“管理员”，当前选中“管理员”标签页（下方有蓝色横线）。右上角有一个关闭图标“X”。

面板标题为：| 添加管理员（左侧有蓝色竖线装饰）。
标题下方有一行提示文字：管理员只可以使用管理后台的部分功能 帮助文档（“帮助文档”为蓝色链接）。

中间区域为权限选择列表，包含多个复选框选项：
- [ ] 安全策略
- [ ] 管理员日志
- [ ] 企业文化
- [ ] 企业信息管理
灰色背景分隔条文字：功能管理
- [ ] 邮箱
- [ ] 通话与会议
- [ ] 文件管理
- [ ] 日历
- [x] 知识库（该选项已被勾选，复选框为蓝色打钩状态，且整行背景高亮显示，有一个手形鼠标光标正指着该复选框）

下方为“高级设置”区域：
- [ ] 可以管理其他管理员（仅能分配自己拥有的权限）

底部左侧显示状态文字：已选 1 个：知识库。
底部右侧有两个按钮：灰色的“取消”按钮和蓝色的“确定”按钮。

界面最右侧边缘有一个垂直悬浮按钮，文字为：欢迎反馈。
