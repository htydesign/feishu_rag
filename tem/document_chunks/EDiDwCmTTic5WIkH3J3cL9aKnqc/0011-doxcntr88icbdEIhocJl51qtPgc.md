# 管理员手册

## Wiki administrators

这张图片展示了管理后台中“Administrator Permissions”（管理员权限）页面的界面截图，用于说明如何在系统中查看和管理具有特定权限（如Wiki权限）的管理员列表，并指示了添加新管理员的操作入口。图中通过蓝色数字圆圈标注了关键操作步骤或区域。

图片中的具体内容及文字如下：

**左侧导航栏：**
- Home
- Organization
- Meeting Rooms
- Workplace
- Billing
- Security
- Reports
- Customization
- Settings（当前展开菜单）
  - Company Info
  - Administrator Permissions（当前选中项，对应标注 2 的位置附近）
  - SSO account login
  - Data Migration
  - Custom stickers
  - Feature Management
- Mail
- Video Meetings
- Help Desk

**顶部面包屑导航：**
Settings / Administrator Permissions

**主要内容区域顶部：**
- 选项卡：Super administrator | Administrator（当前选中，下方有蓝线，旁边标注数字 3）
- 提示文本：Administrators only have access to some features in the admin console. User guide
- 右上角功能链接与按钮：
  - Permissions Group Management
  - + Add Administrator（蓝色按钮，上方标注数字 4）

**筛选与搜索栏：**
- 下拉菜单：Permissions group All
- 下拉菜单：Permission All
- 搜索框：Name/Email/Phone No.
- 复选框：Only those who can manage other administrators

**管理员列表表格：**
表头分为三列：Administrator、Permissions settings、Actions。
