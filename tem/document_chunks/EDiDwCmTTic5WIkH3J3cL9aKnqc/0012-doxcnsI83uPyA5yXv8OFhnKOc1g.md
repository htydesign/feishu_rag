# 管理员手册

## Wiki administrators

这张图片展示了管理后台中点击“Add Administrator”后弹出的添加管理员权限配置界面，用于说明在创建新管理员时如何为其分配具体的功能权限，图中特别演示了勾选“Wiki”权限的操作。

图片中的具体内容及文字如下：

**左侧导航栏：**
- Home
- Organization
- Meeting Rooms
- Workplace
- Billing
- Security
- Reports
- Customization
- Settings（当前展开菜单）
  - Company Info
  - Administrator Permissions（当前选中项，背景高亮）
  - SSO account login
  - Data Migration
  - Custom stickers
- Feature Management
- Mail
- Video Meetings
- Help Desk

**顶部面包屑导航：**
Settings / Administrator Permissions / Add Administrator

**主要内容区域（弹窗形式）：**
- 顶部选项卡：Super administrator | Administrator（当前选中，下方有蓝线）
- 标题：Add Administrator（左侧有蓝色竖线标记）
- 右上角有关闭图标“X”
- 提示文本：Administrators only have access to some features in the admin console. User guide

**权限选择列表（复选框形式）：**
- [ ] Workplace Management
  - [ ] App Management
- [ ] Billing
- [ ] Security Strategy
- [ ] Admin Log
- [ ] Customization
- [ ] Company Info
- Feature Management（灰色背景分隔条）
- [ ] Email
- [ ] Calls and meetings
- [ ] Files
- [ ] Calendar
- [x] Wiki（此项已被勾选，复选框为蓝色打钩状态，整行背景高亮显示。有一个手形鼠标光标正指着该复选框，表示正在进行选择操作）

**高级设置区域：**
- Advanced
- [ ] Can man... administrators (only owned permissions can be assigned)（注：中间部分文字被手形光标遮挡，可见部分为“Can man”和“administrators (only owned permissions can be assigned)”）

**底部状态与操作栏：**
- 左侧显示统计信息：1 selected: Wiki
- 右侧按钮：Cancel | Confirm（蓝色按钮）

Feedback
